== Description ==

WordPress plugin providing complete invoicing and payment management for trades and home service businesses. Features include job estimate builder with material and labor line items, automated invoice generation from completed jobs, client portal for invoice viewing and payment, Stripe and Square payment gateway integration, automatic payment reminders via email and SMS, installment payment schedules for large jobs, quote-to-invoice conversion, sales tax calculation by jurisdiction, subcontractor payment tracking, QuickBooks and Xero CSV export, and annual revenue reporting. Supports plumbers, electricians, HVAC technicians, landscapers, and general contractors. WooCommerce-free, standalone plugin, PHP 8.1+, WordPress 6.x+.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate via WordPress admin > Plugins
3. Configure via Settings > Trades Services Invoice and Payment Plugin
